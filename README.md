# Wrepsk Plugin Repository

This repository is maintained for the convenience of users who still rely on this old plugin repository.

CrystalCast is a video player and streaming plugin for Final Fantasy XIV, bringing YouTube, Twitch, and web media into customizable in-game screens.

- [CrystalCast source code](https://github.com/Wrepsk/crystal-cast)
- [CrystalCast on XIV Mod Archive](https://www.xivmodarchive.com/modid/172389)
- [Documentation and installation](https://github.com/Wrepsk/crystal-cast#readme)

The actual development, releases, documentation, and issue tracking for CrystalCast are maintained in the main repository.
